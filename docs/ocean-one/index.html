How to set it up

1

Add Ocean One to your server. Use the main product page to begin the invite process and make sure the bot has the permissions it needs for moderation, logs, and verification.

2

Open the owner panel. Sign in with your Discord account from the owner panel and select the server you want to manage. The panel is where you configure modules, roles, and automation settings.

3

Review the feature list. Start with the basics: moderation, logging, anti-ping, ticketing, verification, and server keys. You can enable or disable them depending on the server's needs.

4

Set roles and channels. Choose which channels should receive logs, announcements, verification screens, or ticket panels. Keep the permissions tight so only trusted staff can manage configurations.

5

Test it before launch. Run a quick check as a staff member to confirm the bot responds correctly, logs are being recorded, and verification or ticket workflows behave the way you expect.

How to use it

For server owners: use the owner panel to configure protection, verification, tickets, logging, and access controls.

For moderators: rely on configured moderation and logging flows to keep the server clean, consistent, and well documented.

For members: use the verification flow if it's enabled, and follow the configured channels and rules your server sets up.

Common command reference

status

Shows the bot's current status and server health check.

help

Displays the list of available commands and quick usage help.

announce

Broadcasts a message to a configured channel or announcement route.

logs

Pulls or summarizes recent event data from moderation or activity logs.

verify

Starts or checks the verification flow for a user or guild workflow.

ticket

Opens or manages tickets for support, reports, or staff requests.

moderate

Access moderation-specific checks or admin actions depending on configuration.

config

Loads the current settings and configuration for a guild or configured module.
